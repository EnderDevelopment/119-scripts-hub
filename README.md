# 119 SCRIPTS

A highly polished Roblox Lua interface designed around a dark purple and black aesthetic. The interface is designed for mobile and desktop users, with special attention to iPhone usability, touch controls, readable text, and efficient navigation. It features a powerful control panel, smooth animations, modular functionality, and an organized collection of tools. The UI is aggressive, modern, clean, and powerful, with sharp visual hierarchy, subtle borders, and controlled purple lighting.

## Installation
1. Open Roblox Studio.
2. Create a new script or open an existing one.
3. Copy and paste the contents of the Lua files into the script.
4. Save the script.

## Script Placement
- **119ScriptsMain.module.lua**: Place this script in the `StarterGui` or `StarterPlayerScripts` folder.
- **119ScriptsUI.module.lua**: Place this script in the `StarterGui` or `StarterPlayerScripts` folder.

## Usage
1. Run the game in Roblox Studio.
2. The 119 SCRIPTS interface will appear on the screen.
3. Use the control panel and modular tools to interact with the interface.
